# Shell-Profile
My zsh profile for Asahi Linux

In order to use these files,
1. Change the name of *zshrc* file to *.zshrc*
1. Change the name of *vimrc* file to *.vimrc*
1. Change the name of *zsh* folder to *.zsh*
1. Change the name of *vim* folder to *.vim*

Summary: add *.* before each file in this folder.
